# My-Bank
## Running the services

Each directory is a Spring Boot application with its own port.

| Service          | Port |
|------------------|------|
| account          | 8080 |
| transaction      | 8081 |
| reporting        | 8082 |
| authentication   | 8083 |
| frauddetection   | 8084 |

### Run all with the given command bellow

```bash
chmod +x run-all.sh && ./run-all.sh
```
